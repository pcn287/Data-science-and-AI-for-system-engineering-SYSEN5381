# Module 11 Lab 2: Congressional Agent Architecture

This folder contains the lab submission for **AI Architecture Design for a Congressional Agent**.

Focal agent chosen: **Option C — Plain Language Translator**.

Files:

- `focal_agent_prompt.md` — system prompt, retrieval logic, and output format.
- `architecture.md` — Mermaid system diagram and architecture answers.
- `justification.md` — short justification response.
- `congress_lab_submission.md` — combined version for easy submission.

The design focuses on a safe congressional document assistant that translates legal or regulatory text into plain English while preserving meaning, warning about nuance, and enforcing access control before retrieval.
